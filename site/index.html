Kalima, an Arabic word processor

Kalima (كلمة) is a free, open-source, Arabic-first word processor for macOS, Windows and Linux by Nasser Alqahtani. It has an Arabic, right-to-left interface (English is available), right-to-left Arabic documents by default, Arabic spell checking through the macOS and Windows system spell checkers, and opens and saves Word .docx files.

Download the latest release · Source on GitHub
